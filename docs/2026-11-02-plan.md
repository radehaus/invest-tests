# Plan: Mobile Invest-Showcase (Arbeitstitel)

Stand: 2026-11-02

## Ziel

Eine mobile Web-Page auf dem Niveau von Revolut und Trade Republic, die Entscheidern bei der Allianz zeigt, wie sich Fondsanlage und Lebensversicherung in einer modernen Oberfläche anfühlen können. Keine App, sondern ein Link, der auf dem Handy wie eine App wirkt und auf dem Laptop als Telefon-Rahmen erscheint.

## Vorgehen

1. **Neutral bauen.** Graustufen, eine Akzentfarbe, Geist als Schrift. Alle Farben, Radien und Abstände als Tokens in `src/app/globals.css`.
2. **Anforderungen umsetzen.** Jörg schickt die Liste, daraus werden Screens und Flows.
3. **Branding am Ende.** Allianz-Invest-Farben, Logo und Schrift nur über die Tokens tauschen. Keine Farbe steht hart in einer Komponente.

## Stack

| Teil | Wahl | Warum |
|---|---|---|
| Framework | Next.js 16, App Router, statischer Export | App-Gefühl mit vielen interaktiven Teilen, Seitenwechsel ohne Neuladen, React-Ökosystem für Charts und Gesten. Astro wäre für Inhaltsseiten stärker, hier ist fast alles interaktiv. |
| Styling | Tailwind CSS 4 mit eigenen Tokens | schnell, Branding-Tausch an einer Stelle |
| Animation | Motion (früher Framer Motion) | Übergänge, Bottom Sheets, Wischgesten wie bei Revolut |
| Icons | Lucide | neutral, später ersetzbar |
| Daten | Echte Fondsdaten verschlüsselt (`public/vault.json`), fiktive Persona und Verträge als JSON | kein Backend, Details im README |
| Navigation | Hash-Router (`#/broker/fund/<id>`) | läuft auf GitHub Pages ohne Server, Zurück-Taste inklusive |

## Hosting

**Empfehlung: GitHub Pages.** Der Workflow liegt in `.github/workflows/deploy.yml` und baut bei jedem Push auf `main`.

- Kostenlos nur mit öffentlichem Repo. Für ein privates Repo mit Pages braucht es GitHub Pro.
- Die Seite selbst ist öffentlich erreichbar. Echte Daten sind deshalb mit dem Demo-Passwort verschlüsselt. Suchmaschinen sind per `noindex` ausgesperrt.
- URL-Form: `https://radehaus.github.io/<repo>/`. Eine eigene Domain lässt sich später eintragen.

**Vercel lohnt sich hier nicht**, solange kein Passwortschutz oder Vorschau pro Branch gebraucht wird. Wichtig: Der kostenlose Hobby-Plan ist laut Vercel nur für nicht-kommerzielle Nutzung, ein bezahlter Kundenauftrag bräuchte den Pro-Plan.
